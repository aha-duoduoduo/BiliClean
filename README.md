# BiliClean

本项目原先由 GitHub 账号 ahaduoduoduo 发布。该账号被停用后，项目转到当前账号 aha-duoduoduo 继续维护。

为哔哩哔哩 iOS 客户端提供赞助片段跳过、广告过滤、完整视频下载和界面整理的插件。

## 安装

从本仓库 **Releases → Assets** 下载 `BiliClean_版本号.dylib`，使用 IPA 注入工具将它加入哔哩哔哩安装包，完成签名后安装。注入环境需要提供 MobileSubstrate 兼容支持。

安装后，打开 **哔哩哔哩 → 我的 → 设置 → 右上角 BiliClean**，即可调整功能开关。

- IPA 注入用的 Release dylib 只含 `arm64`：哔哩哔哩主程序是 `arm64`，注入工具附带的 `libsubstrate.dylib` 也只有 `arm64`；带 `arm64e` 切片时，iOS 26 会加载 `arm64e` 切片，调用原方法时因指针认证不匹配而闪退。越狱 deb 保留 `arm64`、`arm64e`。最低部署版本为 iOS 14。
- 当前测试通过版本：哔哩哔哩 **8.76.0**；竖屏普通播放器“三个点”、AirPlay 发热和离线缓存并发均已在真机验证。

## 功能

| 功能 | 使用体验 |
| --- | --- |
| 赞助片段跳过 | 根据小电视空降助手的社区标注自动跳过赞助片段，可调整跳过提前量、设置不重复跳过 |
| 完整视频下载 | 下载当前正在播放的完整视频，自动选择账号可获取的最高画质，音视频无损合并后保存到照片 |
| 广告过滤 | 移除开屏、信息流和播放器广告，按需过滤带货内容、相关推荐广告及片尾推荐 |
| 关键词屏蔽 | 按普通关键词或正则表达式过滤内容，每条规则可分别用于推荐、动态和评论 |
| 播放速度 | 设置默认倍速，在竖屏播放器倍速面板中增加 3 倍速 |
| CDN 加速 | 测试播放节点速度，自动选择较快节点，也可手动选择和调整优先顺序 |
| TAB 管理 | 自由选择首页频道、顶部与底部导航项目，单独控制底部发布入口 |
| 界面整理 | 按需隐藏首页直播、图文推荐、推荐理由、互动弹幕及“我的”页不常用服务与大会员推广横幅，将竖屏播放器替换为普通播放器 |
| AirPlay 降温 | 修复 AirPlay 播放时音频输出回调空转导致的发热 |
| 离线缓存并发 | 设置离线缓存同时下载的数量（1–99，默认 3） |
| 大会员画质 | 账号有大会员清晰度试用资格时，可在清晰度面板直接选择大会员清晰度，并隐藏试用横幅与“可试看/试看中”标识 |
| 自动最高清晰度 | 起播后自动切到当前可用的最高清晰度，包含试看清晰度 |
| 设置备份 | 通过剪贴板导出、导入 BiliClean 设置，便于更换应用 ID 或签名后迁移 |

## 使用

### 下载完整视频

1. 在视频播放页打开分享面板。
2. 点击第三个位置的 **下载分享** 或 **下载视频** 按钮
3. 顶部显示下载、合并和保存进度。可以返回列表或切换其他视频

暂不支持 HDR 或杜比视界
需有相册写入权限

### 跳过赞助与调整播放

在 **BiliClean → 播放** 中开启赞助跳过，可设置跳过提前量。片段数据来自 [小电视空降助手](https://bsbsb.top/) 的社区标注。

进入 **CDN 加速** 页面运行测速，选择节点或拖动调整顺序。这里的节点设置用于播放；完整视频下载使用接口返回的原始主备地址。

### 过滤内容与整理界面

在 **屏蔽** 分组中选择要移除的广告类型，并添加关键词规则。在 **首页**、**界面** 分组中调整推荐内容、TAB 和服务入口。不同过滤功能可单独开关，也可通过总开关统一控制。

在 **界面** 分组中开启“移除不常用服务”后，“我的”页的大会员推广横幅会一并移除。

### 大会员画质

在 **界面** 分组开启“大会员画质（试用额度内）”（默认开启）。账号有大会员清晰度试用资格时，在播放器清晰度面板选择带“大会员”标记的清晰度即可播放。开启后会隐藏“剩 N 次大会员清晰度试用”横幅、“成为大会员畅享全部清晰度”按钮，以及清晰度行上的“可试看 / 试看中”标识。

同组的“自动选择最高清晰度”（默认开启）会在起播约 3 秒后自动切到当前可用的最高清晰度，包括试看清晰度；切换全屏不会再退回普通清晰度。

该功能依赖服务端下发的试用资格（`qn_trial_info.trial_able`）。账号没有试用资格时，服务端不提供大会员清晰度，开启开关也不会增加可选画质。

### 离线缓存并发

在 **界面** 分组开启“解除离线缓存并发限制”，再点“同时下载数量”填入 1–99 之间的整数（默认 3）。冷启动 App 后按该数量同时缓存，关闭开关并重启后恢复默认。数值越高越依赖网络、内存和磁盘，不建议超过 10。

## 从源码构建

使用 macOS、Xcode 和 [Theos](https://theos.dev/docs/installation-macos)，配置好 `THEOS` 环境变量后运行：

```bash
make clean release
```

输出文件：

```text
dist/BiliClean_1.0.46.dylib
dist/BiliClean_1.0.46.dylib.sha256
packages/com.ahaduoduoduo.bilibilisp_1.0.46_iphoneos-arm.deb
```

Release dylib 保留越狱默认的 Substrate 依赖 `/Library/Frameworks/CydiaSubstrate.framework/CydiaSubstrate`，由 LCSign 等注入工具改写为 `@loader_path/libsubstrate.dylib` 并附带运行库。

版本号取自 `control`。业务代码使用 Objective-C / Logos，音视频合并和相册保存使用系统 AVFoundation、Photos 框架。

维护者在 GitHub 发布与 `control` 版本一致的 Release（例如 `v1.0.46`）后，发布工作流会自动构建并上传 **dylib 和 SHA-256 校验文件**。
